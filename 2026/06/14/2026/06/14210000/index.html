在手机上 Vibe Coding：UU远程与终端代理的折腾记录

  • 2026-06-14
  • 作者 cong
  • ~1.60K 字

本文最后编辑于 前，其中的内容可能需要更新。

最近有个场景越来越多：不在电脑前的时候，突然想改点代码、跑个脚本、或者干脆就是手痒想敲几行命令。手机虽然屏幕小，但配合 AI 辅助写代码（也就是所谓的 Vibe Coding），其实体验没有想象中那么差。

关键问题是：怎么从手机连到服务器？

UU远程：最省心的方案

UU远程（网易出的远程控制工具）自带终端功能，这可能是目前在手机上 ssh 到服务器最省事的方式了。

优点很明显：

  • 不需要自己搞端口映射、内网穿透这些东西
  • 手机端有专门的终端界面，键盘布局针对命令行做了优化，Tab、Ctrl、方向键都有
  • 延迟在可接受范围内，打几个命令、看看日志完全够用
  • 支持多台主机管理，切换方便

实际用下来，写代码肯定不现实，但做这些事情很舒服：

  • 跑个 docker ps 看看容器状态
  • tail -f 追一下日志
  • 执行个部署脚本
  • 用 vim 改个配置文件里的几行

配合 Claude 或者 ChatGPT 在手机浏览器里生成命令，复制粘贴到 UU远程的终端里执行，这就是一套完整的手机端 Vibe Coding 工作流。

自带终端 App：更自由但要自己搞定网络

如果你用的是 iOS 上的 Termius、a-Shell，或者 Android 上的 Termux，体验会更接近原生终端。这些 App 本身做得都不错，尤其是 Termux，几乎就是一个完整的 Linux 环境。

但问题来了：你的服务器大概率不在公网，或者你不想暴露 SSH 端口。

这时候就得自己搞代理/隧道了。几种常见的路子：

1. WireGuard / Tailscale 组网

最推荐的方案。在手机和服务器上都装一个，组建一个虚拟局域网，然后手机就能直接 ssh user@10.0.0.x 了。

Tailscale 更傻瓜一些，注册登录就能用。WireGuard 需要自己搭服务端，但更轻量、更快。两个方案我都用过，日常使用体感差别不大。

2. Cloudflare Tunnel

如果服务器上有跑 Web 服务，可以用 Cloudflare Tunnel 把 SSH 也暴露出来。手机端通过 Cloudflare 的客户端连接，安全性不错，就是配置稍微麻烦一点。

3. frp / ngrok 内网穿透

老方案了。在公网 VPS 上跑个 frps，家里服务器跑 frpc，把 SSH 端口映射出来。能用，但需要维护一台公网机器，而且 frp 的配置格式改过好几次，每次重新搞都要翻文档。

4. 直接走代理

如果服务器上已经有代理（比如 clash、v2ray），手机装个代理客户端连上，然后通过代理转发 SSH 流量。这个方案最灵活但也最折腾，需要配 ProxyCommand 或者用支持代理的 SSH 客户端。

Termux 里可以直接装 openssh 和 proxychains，在手机上就能搞定整条链路。iOS 这边就麻烦一些，a-Shell 的 SSH 不支持代理配置，Termius 可以但高级功能要付费。

实际体验

说实话，手机上写代码这件事，”能做”和”想做”之间有很大差距。

大部分时候我用手机连服务器，做的都是运维性质的操作：看看服务状态、重启个容器、改个配置。真正写代码的场景不多，除非是那种”就差改一行就能跑通了”的情况。

但 Vibe Coding 改变了这个比例。有了 AI 辅助，你只需要描述意图，AI 生成代码，你复制粘贴执行。手机上的输入量大幅减少，体验也就上来了。以前在手机上敲一行 sed 命令都痛苦，现在直接让 AI 生成，复制过去就行。

所以结论是：手机 Vibe Coding 的可行性，取决于你的网络方案有多顺畅。 UU远程适合懒人（比如我），开箱即用；自带终端 App 适合愿意折腾网络的人，上限更高。两种方式都能用，选哪个看你的折腾意愿和场景需求。
