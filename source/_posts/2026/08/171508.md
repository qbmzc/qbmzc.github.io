## 前言

中兴小方糖系列硬件完全一致，只有固件不同：

- **h196a**：国际版
- **Z500**：国内电信版
- **Z503**：国内移动版
- **Z507**：国内联通版
- **Z506**：国内公版固件

我手上的 Z503 是 v1.0.0 的"坑货"，不支持 Mesh 组网，于是开始折腾刷机。

整个项目开源在 GitHub/Gitee，核心是两个 Python 工具：

- `ztetool.py`：加解密用户配置文件 `config.bin`
- `mod_tags.py`：修改 `tags.bin`（/dev/mtdblock2 tags 分区 dump）

## 1. 开启 Telnet

### 1.1 备份并解密配置

进入路由器后台，在"管理与诊断"里找到"备份用户配置"，备份得到 `config.bin`。该文件使用 AES 加密，密钥和 IV 由设备序列号、MAC 等派生，`ztetool.py` 实现了完整加解密流程（含一个 buggy 的 SHA256 实现，与设备端算法保持一致）：

```bash
uv run ztetool.py -d -r z503 config.bin config_z503.xml
```

解密后得到 XML 格式的用户配置，修改 `TelnetCfg` 表开启 Telnet：

```xml
<Tbl name="TelnetCfg" RowCount="1">
<Row No="0">
<DM name="TS_Enable" val="1" />
<DM name="Wan_Enable" val="0" />
<DM name="Lan_Enable" val="1" />
<DM name="TS_Port" val="23" />
<DM name="TS_UName" val="root" />
<DM name="TS_UPwd" val="root123" />
<DM name="Max_Con_Num" val="5" />
<DM name="Max_Auth_Tries" val="3" />
<DM name="Auth_Lock_Time" val="60" />
<DM name="ProcType" val="0" />
<DM name="Level" val="3" />
</Row>
</Tbl>
```

### 1.2 重新打包并恢复

```bash
uv run ztetool.py -e -r z503 config_z503.xml config_telnet_enabled.bin
```

用修改后的 bin 在后台"恢复用户配置"，系统重启后 Telnet 即开启。账号密码：`root/root123`。

## 2. 扩容 /var

Telnet 进路由器后执行：

```bash
mount -o remount,size=32M /var
```

**这一步必须做。** Z506 V1.0.0.2B2.8000 固件有 20M，超过 /var 默认容量，不扩容刷机时会提示"文件上传失败"。

## 3. 升级固件

1. 进入"系统升级"页面
2. 上传 `zxhnze50x_hv100_fv1002b28000_firmware-20230615093954.bin` 固件
3. 确认升级，系统自动重启后就是 Z506 了
4. 管理密码与 Z503 保持一致

固件可在 [archive.org](https://archive.org/download/zxhnze50x_hv100_fv1002b28000_firmware-20230615093954) 下载。

## 4. Mesh 组网

刷机的目的就是让 Z503 V1.0.0 也能 Mesh 组网：

1. 牙签戳 reset 键约 10 秒，恢复出厂设置
2. 主路由 LAN 口接小方糖 WAN 口，等待 1 分钟自动组网

## 5. 修复 Z506 的"马甲"

进到 Z506 后发现问题：主页上属于 Z506 的图显示不出来，因为设备标识还留在 Z503。

### 5.1 重新开启 Telnet

同第 1 节，用 `-r z506` 重新加解密：

```bash
uv run ztetool.py -d -r z506 config_z506.bin config_z506.xml
# 修改 TelnetCfg 后：
uv run ztetool.py -e -r z506 config_z506.xml config_telnet_enabled_z506.bin
```

### 5.2 备份 tags.bin

```bash
cat /dev/mtdblock2 > /tmp/tags.bin
```

### 5.3 回传 tags.bin

主机起一个 ftpd：

```bash
uv tool run --from pyftpdlib python -m pyftpdlib -w -u user -P 123456 -p 2121
```

路由器上回传：

```bash
wput_ftp /tmp/tags.bin ftp://user:123456@192.168.5.2:2121/tags.bin
```

### 5.4 修改 tags.bin

`tags.bin` 是中兴的 tags 分区，格式为：

```
[0..3]   magic   = 0x33333333
[4..7]   size    = 数据段长度
[8..11]  crc32   = zlib.crc32(data[12:12+size])
[12..]   数据段  = 若干 param 条目（key_len/value_len/reserved/key/value）
```

用 `mod_tags.py` 查看：

```bash
uv run scripts/mod_tags.py tags.bin list
file    : tags.bin
magic   : 0x33333333
size    : 0x13C (316)
crc     : 0x81F8F550
entries : 12
======================================================================
[  0]     0x0100  ->  hex:***
[  1]     0x0101  ->  hex:***
[  2]     0x0400  ->  str:CMCC-2aDc
[  3]     0x0404  ->  str:CMCC-pgCz
[  4]     0x0510  ->  str:***
[  5]     0x0530  ->  str:***
[  6]     0x0701  ->  str:***
[  7]     0x8100  ->  str:ZXHN Z503
[  8]     0x0200  ->  str:***
[  9]     0x0300  ->  str:***
[ 10]     0x8010  ->  str:***
[ 11]     0x0807  ->  str:1
```

（星号为打码的串号等敏感信息，实际都是明文。）

把 Z503 改成 Z506：

```bash
uv run scripts/mod_tags.py tags.bin set 0x8100 "ZXHN Z506"
[+] wrote tags.bin: size=316 crc=0x86F35EF1 total=1048576
[+] set 0x8100 = str:ZXHN Z506
```

脚本会自动重算 CRC，并用 0xFF 填充回原始文件大小（NAND 擦除特性），支持 list / dump / get / set / del / verify 等命令。

### 5.5 刷入 tags.bin

主机起 http 服务：

```bash
python3 -m http.server
```

路由器上下载并刷写：

```bash
wget http://192.168.5.2:8000/tags.bin -O /tmp/tags.bin
cat /tmp/tags.bin > /dev/mtdblock2
```

## 6. 重启

重启后完美收工。
