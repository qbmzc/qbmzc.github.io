当你用 `file` 命令看到 `zlib compressed data`，而压缩软件纷纷报错时，别急着放弃。一个小脚本就能搞定。

<!-- more -->

## 起因

今天收到一个文件，名字是 `20231013140814700-855795.pdf`，但用 `file` 命令一看，它并不是 PDF：

```bash
$ file 20231013140814700-855795.pdf
20231013140814700-855795.pdf: zlib compressed data
```

我试图用 **Keka**（macOS 上的压缩工具）直接打开——失败。将文件改名为 `.gz` 再用 Keka 打开，依然失败，报错信息是：

```
ERROR: Cannot open the file as [gzip] archive
Is not archive
```

难道文件损坏了？还是另有玄机？我决定从头排查。

## 第一步：理解 zlib compressed data

`file` 命令的判断依据是文件开头的"魔法字节"。对于 zlib 压缩数据，典型头部是 `0x78 0x9C`、`0x78 0xDA` 或 `0x78 0x01`。这确实是一种压缩数据，但它**不是**标准的压缩包格式（如 `.zip`、`.gz`）。

**关键区别**：
- **gzip 文件**：头部固定为 `0x1F 0x8B`，包含文件名、时间戳等元信息。
- **zlib 数据流**：只有 2 字节的压缩参数头 + 纯粹的压缩数据，**没有**文件封装。

因此，像 Keka、7-Zip 这类工具会检查文件头，发现不是 `0x1F 0x8B` 就拒绝处理——即使文件内容本身是有效的 zlib 压缩数据。

## 第二步：尝试用命令行解压

我首先尝试了 macOS 自带的 `gunzip`，同样失败：

```bash
$ gunzip 20231013140814700-855795.pdf.gz
gunzip: 20231013140814700-855795.pdf.gz: not in gzip format
```

接着使用 `openssl zlib`，但我的 macOS 版本上的 OpenSSL 未包含该命令。于是转向 Python —— 这个办法几乎在所有系统上都通用。

## 第三步：用 Python 的 zlib 模块解压

Python 内置的 `zlib` 模块可以完美处理原始 zlib 数据流。一行命令搞定：

```bash
$ python3 -c "import sys, zlib; sys.stdout.buffer.write(zlib.decompress(sys.stdin.buffer.read()))" < 20231013140814700-855795.pdf > output.bin
```

运行后没有报错，生成了 `output.bin`。再用 `file` 检查：

```bash
$ file output.bin
output.bin: PDF document, version 1.3
```

**成功了！** 原来文件是一个被裸 zlib 压缩的 PDF 文档。将其重命名为 `.pdf` 即可正常打开。

## 为什么会这样？

这种"裸 zlib 压缩"常见于：
- 某些底层库或嵌入式系统，直接调用 `zlib` 压缩数据，却不加容器格式。
- PDF 生成过程中，部分数据块被单独压缩后拼接。
- 文件在传输或备份时，外层的 gzip/zip 容器头意外丢失。

无论原因如何，压缩软件无法识别，但编程语言中的 zlib 库都能直接解压。

## 解决方案总结

如果你也遇到 `zlib compressed data` 且解压工具无法打开：

1. **确认头部字节**（可选）：
   ```bash
   xxd 文件名 | head -n 1
   ```
   看到 `78 9c`、`78 da` 或 `78 01` 开头，基本确定是原始 zlib 流。

2. **使用 Python 解压**（通用方法）：
   ```bash
   python3 -c "import sys, zlib; sys.stdout.buffer.write(zlib.decompress(sys.stdin.buffer.read()))" < 原文件 > 解压后文件
   ```

3. **检查解压后文件的真实格式**：
   ```bash
   file 解压后文件
   ```

4. **如果解压后仍是 zlib 数据**（例如多层压缩），重复步骤 2 即可。

### 备选工具

- **`zlib-flate`**（来自 `qpdf` 包）：
  ```bash
  brew install qpdf
  zlib-flate -uncompress < 原文件 > 解压后文件
  ```
- **Perl**（如果系统自带）：
  ```bash
  perl -MCompress::Zlib -e 'undef $/; print uncompress(<>)' < 原文件 > 解压后文件
  ```

**附录：一键脚本**

将以下内容保存为 `unzlib.sh`，给予执行权限（`chmod +x unzlib.sh`），然后运行 `./unzlib.sh 你的文件`：

```bash
#!/bin/bash
INFILE="$1"
OUTFILE="${INFILE}.decompressed"
python3 -c "import sys, zlib; sys.stdout.buffer.write(zlib.decompress(sys.stdin.buffer.read()))" < "$INFILE" > "$OUTFILE"
echo "Decompressed to: $OUTFILE"
file "$OUTFILE"
```
