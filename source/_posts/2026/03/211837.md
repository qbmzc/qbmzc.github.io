## 简介

WireGuard 是一种轻量、高性能的 VPN 协议，内核级实现，配置简单，相比 OpenVPN/IPsec 有显著的性能优势。

## 安装

```bash
# macOS
brew install wireguard-tools

# Linux
apt install wireguard

# 也可通过官网下载 GUI 客户端
# https://www.wireguard.com/install/
```

## 密钥生成

```bash
# 生成私钥
wg genkey | tee privatekey

# 生成公钥
wg pubkey < privatekey > publickey
```

## 配置文件

服务端 `/etc/wireguard/wg0.conf`：

```ini
[Interface]
Address = 10.0.0.1/24
ListenPort = 51820
PrivateKey = <server-private-key>

# 客户端 A
[Peer]
PublicKey = <client-a-public-key>
AllowedIPs = 10.0.0.2/32

# 客户端 B
[Peer]
PublicKey = <client-b-public-key>
AllowedIPs = 10.0.0.3/32
```

客户端配置：

```ini
[Interface]
Address = 10.0.0.2/24
PrivateKey = <client-private-key>
DNS = 8.8.8.8

[Peer]
PublicKey = <server-public-key>
Endpoint = your-server.com:51820
AllowedIPs = 0.0.0.0/0, ::/0
PersistentKeepalive = 25
```

## 常用命令

| 命令 | 说明 |
|------|------|
| `wg-quick up wg0` | 启动接口 |
| `wg-quick down wg0` | 关闭接口 |
| `wg show` | 查看连接状态 |
| `systemctl enable wg-quick@wg0` | 设置开机自启 |

## macOS 使用技巧

1. **命令行启动**：`sudo wg-quick up wg0`
2. **GUI 工具**：推荐 [WireGuard macOS App](https://apps.apple.com/app/wireguard/id1451685025)
3. **随航模式**：按需连接（On-Demand）可配置为排除内网段

## 常见问题

### wg-quick 启动报错：bash 版本过低

```
wg-quick: Version mismatch: bash 3 detected, when bash 4+ required
```

macOS 默认 bash 为 3.2，wg-quick 需要 bash 4+。解决方案：

```bash
# 1. 用 brew 安装 bash 4+
brew install bash

# 2. 确认新 bash 路径
which bash
# /opt/homebrew/bin/bash

# 3. 修改 wg-quick 首行 shebang（通过 brew 安装的 wireguard-tools 通常已修复此问题）
# 若仍报错，手动指定 bash 运行
sudo /opt/homebrew/bin/bash /opt/homebrew/bin/wg-quick up wg0
```

如果使用 brew 安装的 `wireguard-tools`，重新安装可自动修复：

```bash
brew reinstall wireguard-tools
```

## 排障

### 能发送不能接收（0 B received, 30 KiB sent）

```

  transfer: 0 B received, 30.21 KiB sent
```

客户端有发送量但无接收量，通常为服务端侧问题：

```bash
# 1. 检查服务端端口是否监听
ss -tulpn | grep 51820

# 2. 检查防火墙是否放行 UDP 51820
iptables -L -n | grep 51820

# 3. 确认服务端 Peer 配置中的 PublicKey 与客户端 PrivateKey 匹配
# 服务端:
# [Peer]
# PublicKey = <client-public-key>   ← 必须与客户端私钥对应
# AllowedIPs = 10.0.0.2/32          ← 必须包含客户端 IP

# 4. 检查 NAT/端口转发（如果服务端在内网）
# 路由器需将 UDP 51820 转发到服务端内网 IP
```

### 通用检查

```bash
# 检查端口是否可达
nc -zvu your-server.com 51820

# 查看 WireGuard 状态
sudo wg show wg0

# 查看连接日志
sudo wg show wg0 latest-handshakes

# 内核日志
sudo dmesg | grep wireguard
```
