# AGENTS.md — qbmzc.github.io

Personal blog built with **Hexo 8.1.2** + **Kratos-Rebirth** theme. Deployed to GitHub Pages.

## Dev commands

| Command | What it does |
|---------|-------------|
| `npm run server` | Dev server at `localhost:4000` |
| `npm run server -- --drafts` | Dev server including draft posts |
| `npm run build` | Generate static site into `public/` |
| `npm run clean` | Delete `public/` & `db.json` |
| `npm run deploy` | Push `public/` to `gh-pages` branch (deploy only; run `build` first) |

## Writing posts

Directly create files at `source/_posts/<YYYY>/<MM>/<HHMMSS>.md`. Frontmatter:

```yaml
title: 文章标题
date: 2026-06-13 17:58:13
tags:
```

The time portion of `date` determines the filename. Example: a post with `date: 2026-06-13 17:58:13` → `source/_posts/2026/06/175813.md`.

Drafts go to `source/_drafts/` (no date field needed).

**Tags & categories**: must be chosen from the existing lists in `scaffolds/metadata.md` — do not invent new ones.

## CI / Deploy

- Push to `main` → GitHub Actions builds & deploys (`.github/workflows/main.yml`).
- Uses Node 22.x, Ubuntu, runs `npm install && npm run deploy`.
- SSH deploy key stored in repo secret `HEXO_DEPLOY_KEY`.
- Git identity: qbmzc / mxlyzc@163.com.
- Timezone set to `Asia/Shanghai`.
- Dependabot enabled for daily npm updates (`.github/dependabot.yml`).

## Config files

| File | Purpose |
|------|---------|
| `_config.yml` | Site-wide Hexo config (URL, permalink, deploy, RSS, etc.) |
| `themes/kratos-rebirth/_config.yml` | Theme config (comments, nav, sidebar, search, widgets, friends) |

## Notes

- Lockfile is `yarn.lock` but CI uses `npm install`. Both work. `package-lock.json` is gitignored.
- No formatter, linter, typechecker, or test suite.
- `public/` is gitignored — generated by `npm run build`.
- `.deploy_git/` is gitignored — checked out by CI as a clone of the deploy repo.
- `scaffolds/` contains post/page/draft templates.
- Theme search generates `search.json` in `public/` (configured in theme config).
- RSS feed at `/rss.xml` (20 posts limit, configured in `_config.yml`).
- `source/.nojekyll` present for GitHub Pages compatibility.
- Theme is vendored under `themes/kratos-rebirth/` (not a symlink).
